# NUSA POWER Mobile App (Flutter)

## Prasyarat
Untuk menjalankan aplikasi ini, Anda harus menginstal **Flutter SDK**.
Saat ini Flutter SDK belum terdeteksi di sistem ini.

Silakan unduh dan instal Flutter SDK dari:
[https://docs.flutter.dev/get-started/install/windows](https://docs.flutter.dev/get-started/install/windows)

## Inisialisasi Proyek
Setelah Flutter terinstal, Anda bisa menginisialisasi proyek di dalam folder ini dengan perintah:
```bash
flutter create .
```

Struktur UI akan dibangun menggunakan arsitektur BLoC/Provider untuk state management, dan library MQTT untuk Flutter (`mqtt_client`) untuk koneksi IoT.
